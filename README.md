# Triangle Checker

This is a simple Maven-based Java project that identifies the type of a triangle.

## Triangle types
- Equilateral: all three sides are equal
- Isosceles: exactly two sides are equal
- Scalene: all three sides are different
- Invalid: sides do not form a valid triangle

## Project structure
- `src/main/java/com/example/triangle/Triangle.java` - working Java logic
- `src/test/java/com/example/triangle/TriangleTest.java` - JUnit test cases

## Run tests
```bash
mvn test
```

## Example
```bash
mvn test
```
